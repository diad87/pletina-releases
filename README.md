# Musify — versiones

Aquí se publican los instaladores de **Musify**, un reproductor de música personal, y el canal del que la app descarga sus actualizaciones automáticas. El código fuente está en un repositorio privado.

## Instalar

Descarga el instalador de tu sistema desde la [última versión](https://github.com/diad87/musify-releases/releases/latest):

- **Windows:** `Musify_x.y.z_x64-setup.exe` — doble clic.
- **Mac:** `Musify_x.y.z.dmg` — arrastrar a Aplicaciones. La primera vez, clic derecho → Abrir.
- **Linux:** `Musify_x.y.z.AppImage` — dar permiso de ejecución y doble clic (o el `.deb` en Ubuntu/Debian).

Una vez instalada, **se actualiza sola**: descarga cada versión nueva en segundo plano y la instala al cerrarla. Todas las actualizaciones van firmadas; la app no instala nada que no lleve esa firma.
