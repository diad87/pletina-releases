# Musify

Reproductor de música personal tipo Spotify para **Windows, Mac y Linux**. Buscas un grupo, eliges un disco y suena: cada canción se reproduce en streaming de solo audio desde YouTube Music, sin anuncios. Biblioteca, playlists, historial y descargas para escuchar sin conexión.

## Instalar

Descarga el instalador de tu sistema desde la [última versión](https://github.com/diad87/musify-releases/releases/latest):

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `Musify_x.y.z_x64-setup.exe` — doble clic |
| Mac (chip de Apple o Intel, macOS 11+) | `Musify_x.y.z_universal.dmg` — arrastrar a Aplicaciones |
| Linux (64 bits) | `Musify_x.y.z_amd64.AppImage` (cualquier distribución) o `.deb` (Ubuntu/Debian) |

Los instaladores no están firmados por Microsoft ni Apple, así que la primera vez el sistema avisa. En la página de cada versión se explica cómo abrirla.

## Se actualiza sola

Una vez instalada (desde la 0.2.0), Musify busca versiones nuevas al arrancar y cada pocas horas, las descarga en segundo plano y las instala al cerrarse. Todas las actualizaciones van firmadas: la app no instala nada que no lleve nuestra firma. En Linux, las actualizaciones automáticas funcionan con el AppImage.
